# NUR Level 3 — premium experience

This branch implements Appearance Studio Pro, Progression Style Designer, Motion & Haptics, Focus Chamber and Dashboard Layout Builder. It retains the original NUR visual identity and does not introduce Material 3.

The existing application ID, signing identity, daily progress formula, historical records and persistent Amanah/Muhasaba definitions must remain unchanged. User assets are local, opt-in and never uploaded. Focus sessions require explicit completion and do not automatically check off tasks or prayers.

The final APK is deferred until feature integration and regression testing are complete. Native refresh-rate requests must report supported modes and respect Android and device restrictions; they must never promise a physical refresh rate that cannot be verified.
