# Level 3 — Power features

Development is staged. No release APK is produced for this level until the feature work and regression checks are complete.

## Scope

- Recurring Amanah schedules (daily, selected weekdays, and one-time), with persistent definitions and date-specific completion.
- Goals with milestones, target dates, progress, and a separate active/archive state.
- A responsive custom NUR interface for managing schedules and goals.
- Preserved prayer, Muhasaba, notes, money, Daily Light, and historical records.
- Local data export and validated import before any destructive replacement.

Native background reminders, widgets, and NUR AI are separate subsequent increments; no simulated notification or AI service is presented as working.
