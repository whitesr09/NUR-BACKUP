# NUR Levels 11–13 — Deen Companion

Implement the agreed Quran & Dhikr Library, Prayer Time Companion, and optional NUR AI in the existing custom NUR design. No Material 3. This is source-only development; do not compile, sign, dispatch, or publish an APK until requested.

Quran text and translations must be attributed to verified editions. Never fabricate verses, hadith, translation attributions, or claim incomplete content is the full Quran. Reading progress and bookmarks are independent of the five-prayer completion formula.

Prayer times must distinguish calculated estimates from confirmed local masjid times. Support user-selected location, calculation method, manual correction and an explicit notification preference. Do not mark prayers complete automatically. Native alarms and adhan playback require separate implementation and device verification.

NUR AI uses an optional user-supplied Gemini API key. Never put a key in a repository, source bundle, URL, log, telemetry or backup. Never transmit personal tracking data by default. Send only explicit user-selected context, identify uncertainty, and use retrieved references rather than fabricated Islamic citations. The assistant is not a mufti and must not issue authoritative fatwas.

Retain original application ID, signing certificate, existing data schemas, history and visual identity. Keep changes isolated and test-only until the user requests an APK.
