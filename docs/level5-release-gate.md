# Release gate

The Deen companion remains development-only. A release requires successful source and browser tests, actual Android compilation and installation testing, verification of original signing identity and update-compatible version code, validation of Quran source data, prayer calculations against trusted references, and a real Gemini connection test with a user-owned key. Do not claim native reminder, secure-key, or display-mode functionality has been verified without corresponding Android results. The user has requested no APK build for this increment.
