# Deen companion implementation

The implementation of roadmap items 11–13 continues on a dedicated development branch. No APK build, signing, release publication, or change to the original NUR or Material 3 repositories is authorized. Preserve all existing user data and the original custom visual identity. Quran and hadith text must be attributed to verifiable sources. Prayer calculations are estimates, not confirmed local masjid times. NUR AI uses an optional user-provided Gemini key, explicit context consent, and no secrets in tracking data, logs, URLs, or backups.
